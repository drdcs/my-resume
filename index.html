Featured Projects

Privacy Guard

Enterprise hybrid PII redaction service powering secure content pipelines and GenAI adoption across Walmart.

Hybrid detection (model + regex)

Layered pipeline: compiled regex and checksum-aware recognizers for structured PII (emails, phones, IDs, payment patterns), then spaCy NER through a customized Presidio analyzer for unstructured entities (names, orgs, locations). Confidence thresholds, allow-lists, and company-context rules reduce false positives on SKUs, internal codes, and operational text.

Custom redact-entity selector

Built a configurable entity selector so tenants choose which entity types to redact per use case — balancing privacy with downstream utility for search, analytics, and LLM grounding — rather than applying a one-size-fits-all mask.

Multi-tenant scale

Multi-tenant service with policy isolation per consuming application, serving 2M+ requests per day in production and widely used across Walmart for PII redaction before content leaves secure boundaries or enters GenAI workflows.

Order Analytics Platform for ML

Streaming order analytics pipeline that feeds Walmart ML teams with reliable, feature-ready data for predictive modeling.

Spark Structured Streaming

Continuous micro-batch ingestion of order and commerce events with windowed aggregations, stateful transforms, watermarks, and checkpointing for fault-tolerant, exactly-once processing — delivering near-real-time analytics tables instead of brittle overnight batch jobs.

Compressed Hive data lake

Persisted curated datasets as Hive-managed columnar tables (ORC/Parquet) using Snappy and Zstandard compression to reduce storage footprint and speed up predicate pushdown and columnar scans for ML feature extraction and BI.

Scaled data sharing
